## Known limitations

These are documented in [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md). They were not fixed in v0.1.0 (by
decision: no agent changes).

1. `qwen2.5:1.5b` may choose the wrong tool or omit `filter_by_age` / `filter_by_date`. Natural-language age and
   date constraints are not guaranteed:
   - "STEM classes for age 8" skipped the age filter in 8 of 8 runs on 2026-11-19;
   - "Find activities in June" returned November–December events.
2. The tool choice can change with the system date alone.
3. `get_activity_details` is reliable only with an explicit activity ID.
4. Traditional Chinese input receives Simplified Chinese output.
5. The summary can contradict the cards; one example said there were no swimming lessons while showing one.
6. Answers take 1–20 s on this Mac. The first question after Ollama starts is slower.
7. Results must be verified against the activity records.
8. No login and no rate limit on the Wi-Fi; plain HTTP.
9. The frontend runs on the CRA dev server (`npm audit` findings); there is no `package-lock.json`.
10. Bay Area data only; saved activities are per browser.

## Documentation link check

```bash
python3 - <<'EOF'
import re, os, glob
def slug(h): return re.sub(r"[^\w\- ]", "", h.strip().lower()).replace(" ", "-")
def anchors(f):
    out, code = set(), False
    for line in open(f):
        if line.startswith("```"): code = not code
        if not code and re.match(r"#{1,6} ", line): out.add(slug(re.sub(r"^#+ ", "", line.rstrip("\n"))))
    return out
bad = n = 0
for f in ["README.md"] + sorted(glob.glob("docs/*.md")):
    for m in re.finditer(r"\]\(([^)\s]+)\)", open(f).read()):
        u = m.group(1)
        if u.startswith(("http", "mailto")): continue
        path, _, frag = u.partition("#"); n += 1
        t = os.path.normpath(os.path.join(os.path.dirname(f), path)) if path else f
        if not os.path.exists(t): print("MISSING", f, u); bad += 1
        elif frag and t.endswith(".md") and frag not in anchors(t): print("BAD ANCHOR", f, u); bad += 1
print(n, "links,", bad, "problems")
EOF
```
